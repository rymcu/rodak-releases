# Rodak

Rodak 是一款桌面应用，用于调试 [Mortise](https://github.com/rymcu/mortise) 平台的 AIoT、OTA、Agent 及 MQTT 网关服务。

## 功能概览

| 模块        | 说明                                                               |
| ----------- | ------------------------------------------------------------------ |
| MQTT 调试器 | 多连接管理、主题订阅/浏览、消息收发、JSON 格式化、Mortise 主题预设 |
| 设备模拟器  | 物模型加载、设备注册/激活、遥测上报、指令监听/ACK、影子交互        |
| OTA 监控    | 固件列表、批次 SSE 实时进度仪表盘                                  |
| 聊天        | 文本对话（SSE 流式）、模型选择、会话历史                           |
| 语音输入    | 麦克风录音 + 云端 STT（OpenAI Whisper API）                        |
| 系统设置    | 主题/语言/字体调整、AI 模型服务配置、关于与法律条款                |
